
# M Electronics - Retail Sales Dashboard

## Project Description
A Python-based retail sales dashboard that analyses
electronic product sales using CSV data and visualizes
business performance through Matplotlib.

## Technologies Used
- Python
- Pandas
- Matplotlib
- NumPy
- Streamlit

## Features
1. Total Revenue
2. Total Orders
3. Total Units Sold
4. Average Order Value
5. Monthly Sales Analysis
6. Product Performance
7. Regional Sales Analysis
8. Salesperson Performance
9. Category-Wise Revenue
10. CSV Export
11. Interactive Filters

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the application:

   python -m streamlit run main.py

5. It will automatically open in browser or Open the local URL displayed in the terminal.
